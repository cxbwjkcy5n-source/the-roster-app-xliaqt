================================================================================
AUTHENTICATION FLOW
================================================================================

WEB:
1. User clicks Google/Apple/GitHub login
2. Opens popup window with /auth-popup?provider=google
3. Popup redirects to backend OAuth endpoint
4. Backend redirects to /auth-callback with token
5. Callback extracts token and sends to parent window
6. Parent window stores token and fetches user session
7. Popup closes automatically

NATIVE:
1. User clicks Google/Apple/GitHub login
2. Opens OAuth provider in browser
3. Backend handles OAuth flow
4. Redirects back to app via deep link (theroster://)
5. BetterAuth handles token storage
6. App fetches user session

EMAIL/PASSWORD:
1. User enters credentials
2. Calls authClient.signIn.email() or authClient.signUp.email()
3. BetterAuth handles authentication
4. Token stored automatically
5. App redirects to roster screen
